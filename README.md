# Cpp OOP Projects | مشاريع البرمجة كائنية التوجه

Practice and projects on object-oriented programming, mainly in C++.

تمارين ومشاريع على البرمجة كائنية التوجه (OOP)، بشكل أساسي بلغة C++.

## Structure | الهيكل

- `Cpp/` — C++ classes (e.g. `clsperson.h`).
- `Java/` — Java programs (e.g. Vogel's approximation method).
- `Archives/` — compressed projects: `Employee`, `clsdevelop`, `clsstring`, `clsutility`.
